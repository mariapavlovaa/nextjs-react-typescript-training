# nextjs-react-typescript-training
Учебни материали, практически задания и проекти, разработени в рамките на проект „От висше образование към заетост“, с фокус върху Next.js, React и TypeScript.
## Упражнение 1
Конфигуриране на работната среда – инсталиране и настройка на Visual Studio Code, Node.js и Next.js. Създаване и първоначална конфигурация на демо проект с Next.js. Запознаване със структурата на проекта и основните принципи на работа с React и TypeScript.
## Упражнение 2

Интерактивност, състояние и форми в React
Тема: Управление на състоянието и обработка на потребителски събития.


- Разграничаване на Server и Client Components.
- Работа с useState за управление на състоянието.
- Обработка на събития – onClick, onChange, onSubmit.
- Условно визуализиране на компоненти.
- Работа със списъци и динамично съдържание.
- Създаване на форми с контролирани полета.
- Основна валидация на потребителски данни.
Практическа задача: Разработване на интерактивна форма за контакт с валидация, съобщения за грешки и потвърждение при успешно попълване.
